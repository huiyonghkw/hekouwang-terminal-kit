Doctor & uninstall体检与卸载

Self-check and a restore-based uninstall.自检，以及从备份还原的卸载。

./doctor.sh · ./uninstall.sh

Self-check自检

doctor
$ ./doctor.sh
$ ./doctor.sh --status
$ ./doctor.sh --fix
$ ./doctor.sh --profile

--status prints the state dashboard only (pinned theme / auto / Node / optical / scene / semantic / Ghostty reload). Full check also covers CLI tools, fonts, Dynamic Profile, ecosystem colors, .zshrc order, and shell startup time.--status 只打状态机仪表盘（钉住的主题 / 跟随 / Node / 光学 / 场景 / 语义 / Ghostty 重载）。完整体检还查 CLI、字体、Dynamic Profile、生态配色、.zshrc 顺序、启动耗时。

Uninstall卸载

uninstall
$ ./uninstall.sh --dry-run
$ ./uninstall.sh

Restores ~/.zshrc from the latest file under ~/.hekouwang-terminal-backups/ (also finds legacy home-root backups). GUI settings go back to real factory defaults via defaults delete.从 ~/.hekouwang-terminal-backups/ 最新备份还原 ~/.zshrc（也兼容家目录根旧备份）。GUI 用 defaults delete 回到真正出厂默认。
