Install安装

Clone, dry-run, install — or migrate an existing .zshrc.克隆、预演、安装 —— 或迁移已有 .zshrc。

./install.sh · ./migrate.sh · CN=1

Quick start快速上手

install
$ git clone https://github.com/huiyonghkw/hekouwang-terminal-kit
$ cd hekouwang-terminal-kit
$ ./install.sh --dry-run
$ ./install.sh
# China network:国内网络： CN=1 ./install.sh
  • --dry-run lists every file and defaults it would touch — nothing written yet.--dry-run 先列出要动的文件与系统设置，此时一个字节都没改。
  • Already have a carefully built ~/.zshrc? Run ./migrate.sh first (then --apply). It moves your aliases into ~/.zshrc.local instead of overwriting.已有多年攒的 ~/.zshrc？先跑 ./migrate.sh（再 --apply）。它把别名搬进 ~/.zshrc.local，不是覆盖。
  • Node manager: interactive pick, or ./install.sh --node fnm|nvm|brew|vfox (remembered).Node 管理器：交互选择，或 ./install.sh --node fnm|nvm|brew|vfox（会记住）。
  • Language: --lang zh or answer once; stored under ~/.config/hekouwang-terminal/lang.语言：--lang zh 或首次问答；记在 ~/.config/hekouwang-terminal/lang。
backups Before replacing ~/.zshrc, a copy goes to ~/.hekouwang-terminal-backups/ — not scattered in your home root. Legacy ~/.zshrc.bak.* files are swept into that folder on install/migrate.覆盖 ~/.zshrc 前会备份进 ~/.hekouwang-terminal-backups/，不再散落家目录根。旧的 ~/.zshrc.bak.* 会在装机/迁移时收进去。
