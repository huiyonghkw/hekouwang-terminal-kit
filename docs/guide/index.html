Why this kit为什么用这套

macOS terminal as code: safe install, safe uninstall, one palette.macOS 终端配置即代码：敢装敢卸，一份色板。

If you juggle terminals, themes, and CLI tools that each keep their own colors, this kit turns one palette into a coherent look — and stays safe to install and remove.如果你在终端、主题、CLI 工具之间来回折腾，而它们各自一套颜色，这套装把一份色板做成统一观感 —— 而且敢装也敢卸。
