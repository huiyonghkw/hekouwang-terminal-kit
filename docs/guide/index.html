Why OneLook为什么是 OneLook

Same colors → same look. Safe to install, safe to uninstall, one palette.同色 → 同观感。敢装敢卸，一份色板。

If you juggle terminals, themes, and CLI tools that each keep their own colors, OneLook turns one palette into a coherent look — and stays safe to install and remove.如果你在终端、主题、CLI 工具之间来回折腾，而它们各自一套颜色，OneLook 把一份色板做成统一观感 —— 而且敢装也敢卸。
