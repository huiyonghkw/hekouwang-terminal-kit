Themes & auto换肤与跟随系统

Switch palettes; follow-system is opt-in and pinning turns it off.换肤；跟随系统是可选的，钉住主题会关掉它。

./theme.sh · --auto off by default

Switch theme换肤

theme
$ ./theme.sh                 # gallery + current画廊 + 当前
$ ./theme.sh tokyo-night
$ ./theme.sh --preview tokyo-night

Open-source build ships three community schemes: catppuccin-mocha, tokyo-night, gruvbox-dark. Brand themes (V2 warm dark/light, …) are in the paid pack.开源版自带三套社区主题：catppuccin-mocha、tokyo-night、gruvbox-dark。品牌主题（V2 米黑/米白等）在付费包。

Follow system appearance跟随系统深浅色

Off by default. Turn on only when you want it:默认关闭。想开时再跑：

auto
$ ./theme.sh --auto
$ ./theme.sh --auto tokyo-night catppuccin-mocha   # custom dark/light pair自定暗/亮配对
$ ./theme.sh --auto off
pin A manual ./theme.sh <name> pins that theme. If follow-system was on, it turns following off — so a dark pick is not overwritten when macOS is in light mode.手动 ./theme.sh <名字> 会钉住该主题。若当时开着跟随，会自动关掉 —— 避免配了黑色却被系统浅色顶回白色。
