Six terminals六终端

iTerm2 · Ghostty · Warp · cmux · Tabby · macOS Terminal.app — one palette, six apps. Free configures iTerm2; paid makes the others follow.iTerm2 · Ghostty · Warp · cmux · Tabby · macOS 自带终端 —— 一份色板，六个 App。开源版配好 iTerm2；付费版让另外五个跟着走。

what “support” means Support here = palette look, not feature parity. Triggers, semantic Cmd-click, window badges, and tmux Control Mode stay iTerm2-only — the other apps have no equivalent. Paid multi-terminal sync is about the same colors, not cloning every iTerm2 capability.这里的「支持」＝配色观感，不是功能对等。Triggers、语义 Cmd-click、窗口水印、tmux Control Mode 仍是 iTerm2 独家 —— 另外五个 App 没有对应物。付费多终端同步管的是同色，不是把 iTerm2 每一项都搬过去。

Per terminal逐个终端

01
iTerm2
Home base. Free and paid both land here first: Dynamic Profiles, Triggers, semantic Cmd-click, blur, status bar. After any theme switch, open a new tab so profile rules reload.大本营。开源与付费都先落在这里：Dynamic Profile、Triggers、语义 Cmd-click、毛玻璃、状态栏。换肤后新开 tab，规则才生效。
02
Ghostty paid
Colors sync on theme switch. Config is not live: press Cmd+Shift+, to reload — a new tab alone is not enough. No Triggers / semantic / badge here.换肤时同步配色。配置不会保存即生效：按 Cmd+Shift+, 重载 —— 只开新标签不够。没有 Triggers / 语义 / 水印。
03
Warp paid
Same palette file + active theme pin. Opacity / blur sweet spots differ from iTerm2 — the paid build writes values that are actually visible, not “almost opaque”.同色文件 + 钉住当前主题。透明度 / 毛玻璃甜区与 iTerm2 不同 —— 付费版写的是肉眼能看出差别的值，不是「几乎不透明」。
04
cmux paid
Terminal panes render through Ghostty, so palette sync follows Ghostty. OneLook also pins sidebarAppearance.matchTerminalBackground so the left sidebar does not stay a grey block. Reload cmux after ./theme.sh if the sidebar looks stale.终端区走 Ghostty 渲染，配色跟 Ghostty 同步。OneLook 还会钉 sidebarAppearance.matchTerminalBackground，避免左侧灰块跟终端割裂。侧栏没跟上就重启 cmux。
05
Tabby paid
Writes terminal.colorScheme, main font, Symbols Nerd Font fallback, and scene-driven appearance.vibrancy / opacity into ~/Library/Application Support/tabby/config.yaml. Quit Tabby fully after a theme or scene change — vibrancy does not hot-reload.写 terminal.colorScheme、主字体、Symbols 兜底，以及场景驱动的 appearance.vibrancy / opacity 到 config.yaml。换肤或切场景后完全退出 Tabby —— Vibrancy 不会热加载。
06
Terminal.app paid
Default Profile follows the same palette. Scene blur/opacity is patched at deploy time. Like iTerm2, quitting can overwrite prefs from memory — Cmd+Q fully, then reopen. No Triggers, no Dynamic Profile hot-reload.默认 Profile 跟同一份色板。部署时按场景写入毛玻璃/透明度。和 iTerm2 一样，退出时可能用内存配置覆盖 —— 要 Cmd+Q 完全退出 再开。没有 Triggers，没有 Dynamic Profile 热加载。
install rule Paid sync only fires if the app is actually installed. No Ghostty.app → no Ghostty write. Same for Warp / cmux / Tabby / VS Code. Unused apps stay untouched.付费同步只在你真的装了那个 App 时才写。没装 Ghostty.app → 不碰 Ghostty。Warp / cmux / Tabby / VS Code 同理。不用的 App 原样不动。

How it feels day to day日常怎么用

On the paid build, ./theme.sh (picker or by name) is one command for all six terminals you have installed, plus the tool chain. Open source still uses the same command — it only touches iTerm2. Fuzzy pick + ANSI preview work the same either way; see Themes & auto.付费档里，./theme.sh（选肤或按名）一条命令覆盖你已装的六个终端 + 工具链。开源版命令相同 —— 只动 iTerm2。模糊选 + ANSI 预览两边一样；见换肤与跟随。

./doctor.sh --status surfaces Ghostty “config newer than process” so you know to reload. Details: Doctor../doctor.sh --status 会标出 Ghostty「配置比进程新」，提醒你去重载。明细见体检。
