Node managerNode 管理器

fnm / nvm / brew / vfox — keep exactly one.fnm / nvm / brew / vfox —— 只留一套。

./node-mgr.sh · exactly one

Pick one Node version manager. Mixing fnm / nvm / brew node / vfox makes PATH fight itself.只选一套 Node 版本管理器。混用 fnm / nvm / brew node / vfox 会让 PATH 打架。

brewHomebrew single-version node (not a version manager)Homebrew 单版本 node（不是版本管理器）node
