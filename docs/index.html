01
It doesn't overwrite you不覆盖你的东西
Your existing config is moved into another file section by section — three years of aliases, not one line lost. It then really starts a shell to check the syntax, and rolls back if it won't start. 按段落把你原来的配置搬进另一个文件，三年攒的别名一行不丢；写完真起一个 shell 验语法，起不来自动回滚。
02
You can rehearse it装之前能预演
--dry-run lists every file and system setting it would touch, and what it will never touch, before you commit. --dry-run 先把要改哪些文件、写哪些系统设置、什么绝对不碰列成清单给你看。
03
You can get back不想要了能还原
Uninstall restores from a backup rather than deleting things, and returns system settings to the real factory defaults. 卸载是从备份还原，不是删了拉倒；系统设置恢复真正的出厂默认。
04
It checks itself出问题会自检
doctor.sh runs eight checks — tool chain, whether the font actually resolved, config load order, startup time — and tells you how to fix each one. doctor.sh 八项体检 —— 工具链、字体是否真的上屏、配置加载顺序、启动耗时 —— 哪项不对直接告诉你怎么修。
05
It doesn't slow you down不拖慢终端
One line added to shell startup, not a pile of plugins. 只往启动里加一行，不是堆一大摞插件。
06
Everything else you'd expect该有的都有
3 community color schemes, blur, ERROR/WARN auto-coloring, Shift+Enter for multi-line prompts, and the modern CLI set (eza / bat / fzf / fd / zoxide / ripgrep / atuin / delta). 3 套社区配色、毛玻璃、ERROR/WARN 自动标色、Shift+Enter 写多行 prompt，以及现代 CLI 全家桶（eza / bat / fzf / fd / zoxide / ripgrep / atuin / delta）。
honest limit It will not make your terminal faster. It only manages not to slow it down. Anyone promising a one-click beautifier that also speeds things up hasn't measured it. 它不会让终端变快，只做到不拖慢。谁跟你说一键美化还能提速，那是没量过。
